## Segurança de aplicações

Tenho interesse crescente em cibersegurança aplicada ao desenvolvimento de software, especialmente nos seguintes temas:

- Autenticação segura.
- Autorização baseada em papéis.
- Proteção de rotas.
- Validação e sanitização de entradas.
- Prevenção contra SQL Injection.
- Prevenção contra Cross-Site Scripting.
- Proteção contra Cross-Site Request Forgery.
- Gerenciamento seguro de sessões.
- Armazenamento de senhas com hash.
- Controle de exposição de informações.
- Configuração segura de APIs.
- Análise de dependências.
- Testes de segurança em aplicações web.

Busco aplicar segurança desde o início do desenvolvimento, evitando que ela seja tratada apenas como uma etapa posterior.
